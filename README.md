# 算法学习教练

一个本地优先的算法学习规划与刷题记录工具。你告诉它今天有多少时间，它按复习优先级和知识点状态给出最多 3 道题，并为每道题说明推荐理由。完成后写下手写总结，进度会从事件日志自动重算。

它不是题库或判题器，不会执行代码，也不会调用在线平台 API。

## 启动

需要 Node.js 18 或更高版本，不需要安装任何依赖，也不需要运行构建命令。

```powershell
cd algo-coach
node server.js
```

终端会打印本机地址和全部内网 IPv4 地址，例如：

```text
http://127.0.0.1:8787
http://192.168.1.20:8787
```

在本机浏览器打开 `http://127.0.0.1:8787`。手机连接同一 WiFi 后，可以打开终端中显示的内网地址查看进度。

## 本机写入与局域网只读

- 从 `127.0.0.1` 或 `::1` 访问时，可以记录、换题、改预算和写配置。
- 从 `192.168.x.x` 等非回环地址访问时，所有写接口返回 403，页面自动切换为只读。
- P0 没有登录和加密鉴权，不要把端口直接暴露到公网或不受信任的网络。

## 数据位置

所有数据都是可直接阅读和修改的 JSON：

- `data/config.json`：每日预算、复习间隔、目标标签和打分权重。
- `data/problems.json`：题目列表，可手工追加或替换。
- `data/data.json`：只追加的事件日志。程序不会改写或删除历史事件。
- `data/backup/`：每次写事件前自动备份旧日志，保留最近 5 份。

派生状态（Leitner 盒子、到期时间、连续天数、通过率、热力图等）只存在内存中，每次请求都从事件流重新计算。

## 修改配置

常见字段：

```json
{
  "dailyMinutes": 90,
  "reviewRatio": 0.4,
  "maxNewPerDay": 3,
  "maxDailyProblems": 3,
  "tagColdDays": 14,
  "recentDays": 7
}
```

- `dailyMinutes`：默认每日预算。页面中修改预算会追加一条当天 `budget` 事件。
- `maxDailyProblems`：每日推荐总上限。MVP 默认是 3，后续可以调高而不用改代码；同时提高 `maxNewPerDay` 可增加新题装填名额。
- `reviewRatio`：非 `box0` 复习题最多占预算的比例。`box0` 错题不受该比例限制，但仍受每日总上限限制。
- `scopeTags`：只有含这些中文标签的题会进入新题候选池。
- `weights`：弱项、新鲜度、难度匹配和前置知识四项权重。

## 添加题目

在 `data/problems.json` 数组中追加对象，刷新页面即可生效：

```json
{
  "id": "cf-1234A",
  "title": "Example Problem",
  "url": "https://codeforces.com/problemset/problem/1234/A",
  "platform": "Codeforces",
  "difficulty": 2,
  "estMinutes": 40,
  "tags": ["数组", "双指针"]
}
```

规则：

- `id` 必须全局唯一。
- `difficulty` 使用 `1`、`2`、`3` 表示简单、中等、困难。
- `tags` 必须和 `config.json` 中 `scopeTags` 的字符串完全一致。
- `url` 必须是真实页面。无法确认具体题号时，请使用平台官方搜索页。
- `estMinutes` 缺失时按难度使用 20、40、70 分钟。

页面中的“我自己加一道”是临时题，不会写进 `problems.json`。完成后，记录会带一个 `problemSnapshot`，计入累计题数、分钟数和最近记录，但不参与后续自动复习。

## 算法概要

1. 已达到复习日期的题目优先；上次未独立完成的 `box0` 题最急。
2. 长时间未练且水平偏弱的标签补一道。
3. 其余名额按弱项、新鲜度、难度匹配和前置知识打分装填新题。
4. 每日结果优先保留 `box0`，总数受 `maxDailyProblems` 硬上限约束。
5. 换题会追加 `swap` 事件；原题当天不再出现，原题及其最弱标签下的相关题在未来 3 天降低权重。

## HTTP API

| 方法 | 路径 | 用途 |
|---|---|---|
| GET | `/api/state` | 返回配置、今日推荐、统计和最近记录 |
| POST | `/api/record` | 追加完成记录 |
| POST | `/api/budget` | 追加当天预算 |
| POST | `/api/swap` | 追加换题负反馈 |
| POST | `/api/config` | 合并写回部分配置 |
| GET | `/api/export` | 下载完整事件日志 |

写入使用临时文件和原子重命名，不会直接覆盖正式 JSON。失败时返回 `{ "ok": false, "error": "中文错误信息" }`。

## 备份与恢复

写入 `data/data.json` 前，旧文件会复制到 `data/backup/data-<时间戳>-<随机后缀>.json`，只保留最近 5 份。

恢复时先停止服务器，再用任一备份内容替换 `data/data.json`，然后重新执行 `node server.js`。

如果只删除 `data/data.json`，重启会自动创建空事件日志；`config.json` 和 `problems.json` 保持不变。
